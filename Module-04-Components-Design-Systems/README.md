# Module 04: Components and Design Systems

## គោលបំណង

នៅចុងបញ្ចប់ Module នេះ អ្នកអាច៖

- បង្កើត Main components និងប្រើ instances។
- រៀបចំ variants និង component properties។
- ប្រើ styles, variables, collections និង modes។
- រៀបចំ design library និងពិនិត្យ updates។
- បង្កើត mini design system ដែលមាន documentation និង naming convention។

## តម្រូវការមុនរៀន

- អាចបង្កើត Frames និងប្រើ Auto Layout។
- យល់ពី spacing, typography និង colors។
- មាន Figma file សម្រាប់សាកល្បង components និង instances។

## របៀបអនុវត្ត

បង្កើត components ពី UI patterns ដែលប្រើឡើងវិញពិតប្រាកដ។ សាកប្រើ instances ក្នុង consumer screen មួយ ហើយពិនិត្យការប៉ះពាល់មុនទទួល updates ពី library។
