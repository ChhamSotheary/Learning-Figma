# Lesson 01: Layout Fundamentals and Spacing

## គោលបំណង

បន្ទាប់ពីរៀនមេរៀននេះ អ្នកអាចរៀបចំ UI ដោយប្រើ alignment, spacing, hierarchy និង layout guides ដើម្បីឱ្យអេក្រង់ងាយអាន និងមានរបៀប។ ក្នុង Figma ពាក្យ Layout guides ជាឈ្មោះបច្ចុប្បន្នសម្រាប់ជំនួយការរៀបចំ columns, rows និង grids។

## 1. ហេតុអ្វី Layout សំខាន់?

Layout ជារបៀបដាក់ text, image, button និង controls នៅលើអេក្រង់។ Layout ល្អជួយឱ្យអ្នកប្រើយល់ថាត្រូវមើលអ្វីមុន ស្គាល់ធាតុដែលពាក់ព័ន្ធ ស្វែងរក action សំខាន់បានងាយ និងប្រើ interface បានល្អលើទំហំអេក្រង់ខុសៗគ្នា។

កុំដាក់ធាតុដោយចៃដន្យតាមអារម្មណ៍តែប៉ុណ្ណោះ។ ចាប់ផ្តើមពីគោលបំណងរបស់ទំព័រ មាតិកា និងលំហូរដែលអ្នកប្រើត្រូវធ្វើ។

## 2. Alignment

Alignment គឺការតម្រឹមគែម ឬចំណុចកណ្ដាលរបស់ elements ឱ្យស្របគ្នា។ ឧទាហរណ៍៖

- តម្រឹម title, subtitle និង body text ទៅគែមឆ្វេងដូចគ្នា។
- តម្រឹម button នៅក្នុង card ទៅកន្លែងស្របគ្នានៅគ្រប់ card។
- ប្រើ alignment tools នៅ toolbar ឬ right sidebar នៅពេលជ្រើស layers ច្រើន។

ពេលជ្រើស elements ច្រើន សូមពិនិត្យថាតើអ្នកចង់តម្រឹមតាម selection ឬតាម frame។ បន្ទាប់ពី align សូមពិនិត្យចម្ងាយ និងទំហំទទេម្ដងទៀត។

## 3. Spacing និង Visual Rhythm

Spacing គឺចម្ងាយរវាងធាតុ។ កំណត់ច្បាប់ spacing តិចៗដែលអាចប្រើឡើងវិញបាន ឧទាហរណ៍ scale ដែលកើនជាជំហាន 4px ឬ 8px។ វាជាគោលការណ៍ណែនាំ មិនមែនជាច្បាប់ដាច់ខាតទេ។

- ប្រើចន្លោះតូចសម្រាប់ label និង field ដែលជាគូតែមួយ។
- ប្រើចន្លោះធំជាងសម្រាប់បំបែក section ផ្សេងគ្នា។
- ប្រើ spacing ដដែលសម្រាប់ elements ប្រភេទដូចគ្នា។
- កុំដាក់ text និង controls ជាប់ពេក ឬឆ្ងាយរហូតមើលមិនឃើញថាពាក់ព័ន្ធគ្នា។

## 4. Visual Hierarchy

Visual hierarchy បង្ហាញលំដាប់ដែលភ្នែកអ្នកប្រើគួរមើល។ បង្កើតវាដោយទំហំ និងទម្ងន់អក្សរ ពណ៌/contrast ចន្លោះ និងទីតាំង រូបភាព និងការបែងចែក content ជាក្រុម។

សម្រាប់ទំព័រ Product អ្នកអាចដាក់ product name, price និង primary action ឱ្យមើលឃើញច្បាស់ជាងព័ត៌មានបន្ទាប់បន្សំ។ កុំធ្វើឱ្យធាតុគ្រប់យ៉ាងធំ ឬពណ៌ខ្លាំងដូចគ្នា។

## 5. Columns និង Layout Guides

Layout guides ជាជំនួយមើលឃើញនៅក្នុង frame សម្រាប់តម្រឹម content។ អ្នកអាចប្រើ columns សម្រាប់ web page និង grid សម្រាប់ icon ឬ layout ដែលមាន rhythm ច្បាស់។

1. ជ្រើស frame ដែលត្រូវរៀបចំ។
2. បន្ថែម Layout guide ពីផ្នែក Layout guides ក្នុង Design sidebar។
3. ជ្រើសប្រភេទ columns, rows ឬ grid តាមតម្រូវការ។
4. កំណត់ count, gutter និង margin សមស្រប។
5. ដាក់ content ឱ្យតម្រឹមតាម guides។
6. បិទ ឬកែ guides ពេលមិនត្រូវការទៀត។

ឈ្មោះ និងទីតាំង controls អាចផ្លាស់ប្ដូរតាម UI version ឬ plan។ Layout guides គ្រាន់តែជាជំនួយមើលឃើញ មិនមែនជាធាតុដែល export ទៅ UI ដោយស្វ័យប្រវត្តិទេ។

## 6. អនុវត្តក្នុង Figma

បង្កើត frame សម្រាប់ landing page មួយ ហើយរៀបចំ header មាន logo/navigation/button, hero មាន headline/supporting text/action, content section មាន card បី និង footer មាន links/contact details។

ប្រើ column guides ដើម្បីរៀបចំ desktop frame។ កំណត់ alignment និង spacing ជាច្បាប់សាមញ្ញ ហើយដាក់ឈ្មោះ layers ឱ្យងាយរក។ បង្កើត duplicate មួយ រួចលាក់ guides ដើម្បីពិនិត្យថា design មើលទៅមានរបៀបដោយមិនពឹងលើ grid ប៉ុណ្ណោះ។

## កំហុសទូទៅ

- ប្រើ spacing ខុសគ្នាច្រើនដោយគ្មានមូលហេតុ។
- តម្រឹមតែធាតុមួយចំនួន ហើយទុកធាតុស្រដៀងគ្នាមិនស្របគ្នា។
- ប្រើ grid ដោយមិនគិតពី content។
- បង្កើត hierarchy ដោយពណ៌ខ្លាំងគ្រប់កន្លែង។
- ភ្លេចពិនិត្យ layout ពេលបិទ guides។
