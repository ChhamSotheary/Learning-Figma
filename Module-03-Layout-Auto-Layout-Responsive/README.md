# Module 03: Layout, Auto Layout and Responsive Design

## គោលបំណង

នៅចុងបញ្ចប់ Module នេះ អ្នកនឹងអាច៖

- រៀបចំ alignment, spacing, hierarchy និង Layout guides។
- បង្កើត Auto Layout frames សម្រាប់ buttons, cards និង content lists។
- ប្រើ Hug, Fill និង Fixed sizing តាមតម្រូវការ។
- យល់ពី constraints នៅក្នុង frame ធម្មតា។
- សាកល្បង និងកែ layout សម្រាប់ Mobile, Tablet និង Desktop។
