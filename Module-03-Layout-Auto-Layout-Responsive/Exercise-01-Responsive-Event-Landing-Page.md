# Exercise 01: Responsive Event Landing Page

## គោលដៅ

អនុវត្ត layout, spacing, Auto Layout និង constraints ដោយបង្កើត event landing page ដែលសម្របទៅ Desktop, Tablet និង Mobile។

## Brief

រចនា landing page សម្រាប់ workshop ឬ conference មួយ។ ត្រូវមាន៖

- Header និង navigation។
- Hero title, summary, date និង registration button។
- Speaker cards យ៉ាងហោចណាស់ ៣។
- Agenda យ៉ាងហោចណាស់ ៤ sessions។
- Footer មាន contact និង social links។

## តម្រូវការរចនា

- បង្កើត frames ចំនួន ៣ សម្រាប់ទំហំអេក្រង់ខុសៗគ្នា។
- ប្រើ Layout guides សម្រាប់តម្រឹម desktop content។
- ប្រើ Auto Layout សម្រាប់ header, buttons, cards និង agenda rows។
- ប្រើ constraints សម្រាប់ child layers ដែលត្រូវនៅជាប់គែមក្នុង frame ធម្មតា។
- កំណត់ spacing scale និងប្រើឱ្យស្របគ្នា។
- ដាក់ឈ្មោះ frames/layers ឱ្យងាយយល់។
- សាក title និង speaker name ដែលវែង ដើម្បីពិនិត្យ overflow។
- បង្កើត prototype link ពី CTA ទៅ confirmation screen។

## ដំណើរការ

1. សរសេរបញ្ជី content និងលំដាប់សារមុនចាប់ផ្ដើម។
2. រៀបចំ Desktop frame និង guides។
3. បង្កើត layout ដោយ Auto Layout សម្រាប់ content ដែលមាន flow។
4. ចម្លងទៅ Tablet និង Mobile ហើយកែ structure តាម content។
5. សាក resize និង content variations។
6. ពិនិត្យ hierarchy, contrast, spacing និង CTA។
7. ចែករំលែក link ជាមួយអ្នកពិនិត្យ និងកត់ត្រា feedback។

## Rubric សម្រាប់វាយតម្លៃ

- Layout និង alignment មានស្ថិរភាព: 25%
- Responsive behavior និង breakpoint decisions: 25%
- Auto Layout/constraints ប្រើត្រឹមត្រូវ: 20%
- Hierarchy និងភាពងាយអាន: 15%
- Prototype, naming និង file organization: 15%

## Self-review

- តើ design អាចទ្រាំនឹង title ឬ description វែងបានទេ?
- តើ CTA អាចរកឃើញ និងចុចងាយនៅគ្រប់ទំហំទេ?
- តើ layer ណាខ្លះប្រើ Auto Layout ហើយហេតុអ្វី?
- តើ layout ផ្លាស់ប្ដូរនៅ breakpoint ដោយសារអ្វី?
- តើមាន overflow ឬ layer ដែលតម្រឹមមិនស្របគ្នាដែរឬទេ?

## បន្ទាប់ពីបញ្ចប់

រក្សា design ជា portfolio project មួយ។ សរសេរពីបញ្ហាដែលបានដោះស្រាយ, ការសម្រេចចិត្ត responsive និង feedback ដែលទទួលបាន។ បន្ទាប់មកបន្តទៅ Module 04: Components និង Design Systems។
