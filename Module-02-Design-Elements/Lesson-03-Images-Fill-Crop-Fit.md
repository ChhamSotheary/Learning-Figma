# Lesson 03: Images, Fill, Crop and Fit

## 1. ការប្រើរូបភាពក្នុង UI
រូបភាពជួយបង្ហាញផលិតផល បរិយាកាស និងព័ត៌មានឱ្យអ្នកប្រើយល់បានលឿន។ សម្រាប់ E-commerce រូបភាពផលិតផលមានសារៈសំខាន់ខ្លាំង។

## 2. ដាក់រូបភាពក្នុង Figma
វិធីទូទៅ:
1. បង្កើត Rectangle ឬ Frame។
2. ជ្រើស Fill នៅ Properties panel។
3. ប្ដូរប្រភេទ Fill ទៅ Image។
4. ជ្រើសរូបភាពពីកុំព្យូទ័រ។
5. កែរបៀបបង្ហាញរូបភាព។

អ្នកក៏អាចប្រើ Place image tool តាម Figma UI ដើម្បីដាក់រូបភាពចូល Canvas។

## 3. Fill, Fit និង Crop
- **Fill**៖ ពង្រីករូបភាពឱ្យពេញប្រអប់។ ផ្នែកខ្លះអាចត្រូវបានកាត់ចេញ។
- **Fit**៖ បង្ហាញរូបភាពទាំងមូលក្នុងប្រអប់។ អាចមានចន្លោះទំនេរ។
- **Crop**៖ អនុញ្ញាតឱ្យកំណត់ផ្នែករូបភាពដែលចង់បង្ហាញ។
- **Tile**៖ បង្ហាញរូបភាពជាលំនាំដដែលៗ ប្រសិនបើជម្រើសនេះមានសម្រាប់ Fill នោះ។

## 4. កែរូបភាពឱ្យសម
- រក្សាសមាមាត្ររូបភាព (Aspect ratio) នៅពេល Resize។
- ជ្រើស Crop ដើម្បីបង្ហាញផ្នែកសំខាន់។
- ប្រើរូបភាពមានគុណភាព និងមិនព្រិល។
- កុំឱ្យរូបភាពបាំងអក្សរ ឬប៊ូតុងសំខាន់។

## 5. គំរូ Product image
សម្រាប់ Product card អាចប្រើ Frame 160 × 160 px ហើយដាក់រូបភាពផលិតផលដោយ Fill។ បន្ទាប់មកពិនិត្យថាផលិតផលមិនត្រូវបានកាត់ផ្នែកសំខាន់ៗចេញ។

2. ដាក់រូបភាពផលិតផលមួយ។

4. ប្រើ Crop ដើម្បីផ្លាស់ប្តូរផ្នែករូបភាពដែលបង្ហាញ។
5. ប្រៀបធៀបលទ្ធផល ហើយជ្រើសរើសរបៀបដែលសមស្រប។
