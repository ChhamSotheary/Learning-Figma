# Lesson 04: Masking, Opacity and Effects

## 1. Masking ជាអ្វី?
Masking គឺជាវិធីប្រើ Shape ឬ Layer មួយដើម្បីកំណត់ផ្នែកដែលអាចមើលឃើញពី Layer ផ្សេង។

ឧទាហរណ៍: ប្រើ Circle ជា Mask ដើម្បីធ្វើឱ្យរូប Profile ក្លាយជារូបរាងមូល។

## 2. របៀបអនុវត្ត Mask
1. ដាក់រូបភាព និង Shape នៅក្នុង Canvas។
2. រៀបចំ Shape ឱ្យគ្របលើផ្នែករូបភាពដែលចង់បង្ហាញ។
3. ជ្រើស Shape និង Image តាមលំដាប់ដែល Figma ត្រូវការ។
4. ប្រើ Use as Mask តាម Toolbar ឬ Context menu។
5. កែទីតាំង និងទំហំរូបភាពនៅក្នុង Mask។

ចំណាំ: លំដាប់ Layer អាចប៉ះពាល់ដល់លទ្ធផល Mask។

## 3. Opacity
Opacity គឺកម្រិតភាពមើលឃើញរបស់ Layer។
- 100%៖ មើលឃើញពេញលេញ។
- 50%៖ មើលឃើញពាក់កណ្ដាល។
- 0%៖ មើលមិនឃើញ។

ប្រើ Opacity ដើម្បីបង្កើត Overlay ឬធ្វើឱ្យ Element មួយមិនសូវលេចធ្លោ។

## 4. Effects
Effects អាចជួយបង្កើតជម្រៅ និងបំបែក Element ពីផ្ទៃខាងក្រោយ។

- **Drop shadow**៖ ស្រមោលនៅខាងក្រៅ។
- **Inner shadow**៖ ស្រមោលនៅខាងក្នុង។
- **Layer blur**៖ ធ្វើឱ្យ Layer ព្រិល។
- **Background blur**៖ ធ្វើឱ្យផ្ទៃខាងក្រោយខាងក្រោយ Layer ព្រិល។

## 5. គន្លឹះប្រើ Effects
- ប្រើ Shadow ស្រាលៗ មិនគួរខ្លាំងពេក។
- កុំប្រើ Blur ដោយគ្មានគោលបំណង។
- រក្សា Style ឱ្យស៊ីសង្វាក់គ្នាទូទាំង Website។
- ពិនិត្យថា Text និង Button នៅតែអាន និងប្រើបានច្បាស់។

## Practice
1. បង្កើត Profile image ជារង្វង់ដោយប្រើ Mask។
2. បង្កើត Card មួយ។
3. ដាក់ Drop shadow ស្រាលលើ Card។
4. បង្កើត Overlay ពណ៌ខ្មៅ Opacity 40% លើរូបភាពមួយ។
5. សាកល្បង Background blur ប្រសិនបើអាចប្រើបាន។

1. Masking មានតួនាទីអ្វី?

3. Drop shadow ប្រើសម្រាប់អ្វី?
4. Layer blur ខុសពី Background blur ដូចម្តេច?
