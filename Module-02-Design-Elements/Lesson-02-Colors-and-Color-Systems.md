# Lesson 02: Colors and Color Systems

## 1. Color ក្នុង UI Design
ពណ៌ជួយបង្ហាញអត្តសញ្ញាណ បង្កើតអារម្មណ៍ និងបញ្ជាក់សកម្មភាពសំខាន់ៗរបស់ Website ឬ App។

## 2. ប្រភេទពណ៌ដែលគួរស្គាល់
- **Primary color**៖ ពណ៌សំខាន់របស់ Brand ឬ UI។
- **Secondary color**៖ ពណ៌ជំនួយ។
- **Background color**៖ ពណ៌ផ្ទៃខាងក្រោយ។
- **Text color**៖ ពណ៌អក្សរ។
- **Accent color**៖ ពណ៌សម្រាប់ចំណុចដែលចង់ឱ្យអ្នកប្រើចាប់អារម្មណ៍។
- **Status colors**៖ ពណ៌បង្ហាញ Success, Warning, Error ឬ Information។

## 3. HEX និង RGB
HEX ជាទម្រង់សរសេរកូដពណ៌ ដូចជា `#2563EB`។ RGB ប្រើតម្លៃ Red, Green និង Blue។

នៅក្នុង Figma អ្នកអាចបញ្ចូល HEX នៅក្នុង Color picker។

## 4. Color palette
Color palette គឺជាក្រុមពណ៌ដែលបានជ្រើសរើសសម្រាប់ប្រើក្នុង Design មួយ។

គំរូសម្រាប់ E-commerce:
- Primary: `#2563EB`
- Dark text: `#111827`
- Secondary text: `#6B7280`
- Background: `#F9FAFB`
- White: `#FFFFFF`
- Success: `#16A34A`
- Error: `#DC2626`

អ្នកអាចកែពណ៌ទាំងនេះតាម Brand របស់ Project។

## 5. Color Styles
1. ជ្រើសរើស Shape ឬ Text layer។
2. បើក Fill color picker។
3. ជ្រើសពណ៌ ឬបញ្ចូល HEX។
4. បង្កើត Color Style តាម Figma UI បច្ចុប្បន្ន។
5. ដាក់ឈ្មោះដូចជា `Primary/500`, `Text/Primary`, `Background/Default`។

## 6. Contrast និង Accessibility
អក្សរត្រូវមានភាពខុសគ្នាច្បាស់ពីផ្ទៃខាងក្រោយ ដើម្បីងាយអាន។ កុំប្រើតែពណ៌ដើម្បីបង្ហាញ Error ឬ Success ប៉ុណ្ណោះ គួរបន្ថែមអក្សរ ឬ Icon ផងដែរ។
