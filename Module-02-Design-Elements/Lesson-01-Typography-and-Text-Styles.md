# Lesson 01: Typography and Text Styles

## 1. Typography ជាអ្វី?
Typography គឺជាការជ្រើសរើស និងរៀបចំអក្សរឱ្យងាយអាន មានលំដាប់ និងសមស្របនឹងគោលបំណងរបស់ UI។

ឧទាហរណ៍ នៅលើ E-commerce page:
- ឈ្មោះផលិតផល៖ អក្សរធំ និងដិតជាង
- តម្លៃ៖ ងាយសម្គាល់
- ព័ត៌មានលម្អិត៖ អក្សរតូចជាង ប៉ុន្តែអានច្បាស់

## 2. Text properties សំខាន់ៗ
ជ្រើសរើស Text layer រួចមើលផ្នែក Typography នៅ Properties panel។

- **Font family**៖ ប្រភេទពុម្ពអក្សរ
- **Font weight**៖ កម្រាស់អក្សរ ដូចជា Regular, Medium, Semibold, Bold
- **Font size**៖ ទំហំអក្សរ
- **Line height**៖ ចន្លោះបន្ទាត់
- **Letter spacing**៖ ចន្លោះរវាងតួអក្សរ
- **Text alignment**៖ តម្រឹមឆ្វេង កណ្ដាល ឬស្ដាំ

## 3. បង្កើត Visual hierarchy
Visual hierarchy ជួយឱ្យអ្នកមើលដឹងថាត្រូវអានអ្វីមុន។

ឧទាហរណ៍សម្រាប់ Product card:
- Product name: 18 px, Semibold
- Price: 16 px, Bold
- Description: 14 px, Regular
- Small label: 12 px, Medium

ទំហំទាំងនេះគ្រាន់តែជាគំរូសម្រាប់អនុវត្ត មិនមែនជាច្បាប់ថេរទេ។

## 4. Text Styles
Text Style អនុញ្ញាតឱ្យរក្សាទុកការកំណត់អក្សរ ដើម្បីប្រើឡើងវិញ និងរក្សាភាពស៊ីសង្វាក់គ្នា។

ជំហានអនុវត្ត:
1. បង្កើត Text layer មួយ។
2. កំណត់ Font family, Weight, Size និង Line height។
3. បង្កើត Style ពី Typography section តាម Figma UI បច្ចុប្បន្ន។
4. ដាក់ឈ្មោះឱ្យមានរបៀប ដូចជា `Heading/H1`, `Body/Regular`, `Label/Small`។
5. ជ្រើស Text layer ផ្សេង ហើយប្រើ Style ដែលបានបង្កើត។

## 5. គន្លឹះ
- កុំប្រើ Font ច្រើនប្រភេទពេកក្នុង UI មួយ។
- រក្សាទំហំអក្សរឱ្យមានលំដាប់។
- ត្រូវពិនិត្យថាអក្សរអានបានល្អលើអេក្រង់តូច។
- កុំប្រើពណ៌អក្សរ និងផ្ទៃខាងក្រោយដែលមាន contrast ទាបពេក។

## Practice
បង្កើត Text Styles ចំនួន 4:
1. Heading / H1
2. Heading / H2
3. Body / Regular
4. Caption / Small

បន្ទាប់មកប្រើ Styles ទាំងនេះក្នុង Mobile E-commerce screen របស់អ្នក។
