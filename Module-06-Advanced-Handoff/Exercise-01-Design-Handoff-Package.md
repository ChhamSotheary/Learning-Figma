# Exercise 01: Prepare a Design Handoff Package

## គោលដៅ

រៀបចំ Figma file មួយដែល developer អាចស្វែងរក screens, inspect properties, យល់ responsive behavior និង export assets ដោយមិនចាំបាច់សួរព័ត៌មានមូលដ្ឋានឡើងវិញ។

## តម្រូវការ

ប្រើ project ពី Module 03 ឬ 04 ហើយរៀបចំ៖

- Pages និង frames មានឈ្មោះច្បាស់។
- Desktop, Tablet និង Mobile reference frames។
- Component states សម្រាប់ button និង form field។
- Annotations សម្រាប់ responsive behavior និង interactions ដែលមើលមិនឃើញក្នុង screenshot។
- Export configurations សម្រាប់ logo, icons និង imagery។
- Handoff notes មាន open questions និង changelog សង្ខេប។
- ប្រើ Ready for dev/Dev Mode ប្រសិនបើ plan និង permission អនុញ្ញាត។

## Review Checklist

អ្នកពិនិត្យអាចរកឃើញ primary flow, state variations, responsive rules, spacing/type/asset specs និង export files បានឬទេ? សាកឱ្យអ្នកដទៃបើក file ហើយធ្វើតាម checklist ដោយមិនពន្យល់មាត់ជាមុន។

## Rubric

- File organization: 20%
- Responsive specifications: 25%
- Component states and annotations: 20%
- Asset export and naming: 20%
- Open questions/changelog: 15%

## Deliverables

- Figma file/link ដែលមាន handoff-ready pages។
- Exported assets ឬ export configurations។
- Handoff notes និង open questions។
