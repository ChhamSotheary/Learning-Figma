# Figma UI/UX Design Course

វគ្គសិក្សា Figma UI/UX Design ពី Beginner ដល់ Advanced សម្រាប់អ្នកចាប់ផ្តើមរៀនរចនា Website និង Mobile App។

## Learning Goals
- យល់ពី UI និង UX។
- ប្រើ Figma interface និង tools។
- បង្កើត Frames, Layers, Components និង Auto Layout។
- រៀបចំ Responsive Design និង Design Systems។
- បង្កើត Interactive Prototypes។
- រៀបចំ Design Handoff សម្រាប់ Developer។

## Course Modules
1. Figma Fundamentals
2. Design Elements: Typography, Colors & Images
3. [Layout, Auto Layout & Responsive Design](Module-03-Layout-Auto-Layout-Responsive/README.md)
4. Components & Design Systems
5. Prototyping & Interaction
6. Advanced Figma & Design Handoff
7. Plugins & Final Project

## Study Method
អានមេរៀនតាមលំដាប់ អនុវត្តក្នុង Figma ធ្វើលំហាត់ និងបញ្ចប់ Mini Projects មុនបន្តទៅ Module បន្ទាប់។
