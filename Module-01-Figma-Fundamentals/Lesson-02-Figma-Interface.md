# Lesson 02: Understanding the Figma Interface

## 1. Open Figma
1. ចូលទៅកាន់ [Figma](https://www.figma.com/)។
2. Sign in ឬបង្កើត Account។
3. បង្កើត Design file ថ្មី។
4. ស្គាល់ផ្នែកសំខាន់ៗនៅក្នុង Editor។

## 2. Main Areas of the Editor

### A. Toolbar
Toolbar មាន Tools សម្រាប់ជ្រើសរើស និងបង្កើត Design Elements ដូចជា៖
- Move / Select
- Frame
- Shapes
- Pen
- Text
- Comments និង Actions ផ្សេងៗ

ទីតាំង Toolbar អាចខុសគ្នាតាម Figma interface និងទំហំអេក្រង់។

### B. Layers Panel
Layers Panel បង្ហាញធាតុទាំងអស់នៅក្នុង Page ដូចជា Frames, Text, Shapes និង Images។

ឧទាហរណ៍៖
```
Home Page
├── Header
│   ├── Logo
│   └── Search
├── Hero Section
│   ├── Heading
│   └── Button
└── Product Section
    ├── Product Card 01
    └── Product Card 02
```

### C. Canvas
Canvas គឺជាផ្ទៃធ្វើការ ដែលអ្នកដាក់ និងរៀបចំ Design Elements។

### D. Properties Panel
Properties Panel បង្ហាញការកំណត់របស់ Object ដែលបាន Select ដូចជា៖
- Position (X, Y)
- Size (W, H)
- Fill និង Stroke
- Corner radius
- Typography
- Effects

## 3. Navigate the Canvas
- Zoom: ប្រើ Zoom control ឬ keyboard shortcuts ក្នុង Figma។
- Pan: ប្រើ Space + Drag ដើម្បីផ្លាស់ទីទិដ្ឋភាព Canvas។
- Select object: ចុចលើ Object ក្នុង Canvas ឬ Layers Panel។
- Rename layer: Double-click លើឈ្មោះ Layer។

Shortcut អាចខុសគ្នាតាម Operating System និង Figma updates។ ពិនិត្យ Shortcut menu ក្នុង Figma សម្រាប់បញ្ជីថ្មីបំផុត។

## 4. Create and Organize a Page
1. បង្កើត Page ឈ្មោះ `01 - Mobile App`។
2. បង្កើត Frame មួយ។
3. Rename Frame ជា `Home Screen`។
4. បង្កើត Rectangle និង Text នៅក្នុង Frame។
5. Rename Layers ឱ្យមានន័យ។

## 5. Why Layer Naming Matters
ជៀសវាងឈ្មោះទូទៅដូចជា `Rectangle 12` ឬ `Text 8`។ ប្រើឈ្មោះដែលពិពណ៌នាតួនាទី៖
- `Header`
- `Logo`
- `Search Field`
- `Primary Button`
