# Exercise 01: Mobile E-commerce Home Screen

## Goal
អនុវត្តការប្រើ Frame, Text, Shapes, Fill, Stroke, Corner Radius និង Layer organization ដើម្បីបង្កើត Home Screen សម្រាប់ Mobile E-commerce App។

## Requirements
បង្កើត Mobile Frame មួយ (ឧទាហរណ៍ 390 × 844 px) ដែលមាន៖

1. **Header**
   - Shop name ឬ Logo text
   - Profile icon placeholder

2. **Welcome Section**
   - Heading: `Discover Products`
   - Short description មួយបន្ទាត់

3. **Search Field**
   - Rectangle មានជ្រុងមូល
   - Placeholder: `Search products...`

4. **Featured Product Card**
   - Image placeholder (Rectangle)
   - Product name
   - Price
   - Button: `View Product`

5. **Bottom Navigation**
   - Home
   - Search
   - Cart
   - Profile

## Step-by-step
1. បង្កើត Frame និង Rename ជា `E-commerce Home`។
2. បង្កើត Header ដោយ Text និង Shapes។
3. បន្ថែម Heading និង Description។
4. បង្កើត Search field ដោយ Rectangle និង Text។
5. បង្កើត Product Card ដោយ Rectangle, Text និង Button។
6. បង្កើត Bottom Navigation។
7. Rename Layers ឱ្យច្បាស់។
8. ពិនិត្យ Alignment, Spacing និងភាពងាយស្រួលអាន។

## Suggested Layer Structure
```
E-commerce Home
├── Header
│   ├── Shop Logo
│   └── Profile
├── Welcome Section
│   ├── Heading
│   └── Description
├── Search Field
├── Featured Product Card
│   ├── Product Image
│   ├── Product Name
│   ├── Product Price
│   └── View Product Button
└── Bottom Navigation
```

- [ ] Buttons និង Search field មានរូបរាងច្បាស់។

- [ ] Elements មិនជាន់គ្នា។
