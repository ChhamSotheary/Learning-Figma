# Lesson 01: Introduction to UI/UX and Figma

## 1. What is Figma?
**Figma** គឺជា Design Tool សម្រាប់បង្កើត User Interface (UI), Website Design, Mobile App Design និង Interactive Prototype។ វាដំណើរការតាម Browser និងគាំទ្រការធ្វើការជាក្រុម។

ឧទាហរណ៍៖ មុនពេល Developer សរសេរ HTML និង CSS សម្រាប់ Online Shop គេអាចប្រើ Figma ដើម្បីរៀបចំរូបរាង Website ជាមុន។

## 2. What is UI?
**UI (User Interface)** គឺជាផ្នែកដែលអ្នកប្រើប្រាស់មើលឃើញ និងអាចចុច ឬប្រើប្រាស់បាន។

ឧទាហរណ៍៖
- Logo និង Navigation menu
- Buttons និង Search box
- Product cards
- Colors និង Typography

## 3. What is UX?
**UX (User Experience)** គឺជាបទពិសោធន៍របស់អ្នកប្រើប្រាស់ នៅពេលប្រើ Website ឬ Application។

សំណួរដែល UX Designer គិត៖
- តើអ្នកប្រើអាចរកផលិតផលបានងាយទេ?
- តើការបន្ថែមផលិតផលទៅ Cart ងាយស្រួលទេ?
- តើអត្ថបទ និងប៊ូតុងអាចយល់បានច្បាស់ទេ?
- តើ Checkout មានជំហានច្រើនពេកឬទេ?

## 4. UI vs UX

| UI | UX |
|---|---|
| ផ្តោតលើរូបរាង និងចំណុចប្រទាក់ | ផ្តោតលើបទពិសោធន៍ |
| Colors, buttons, typography | Usability, flow, accessibility |
| អ្វីដែលអ្នកប្រើមើលឃើញ | ភាពងាយស្រួលពេលប្រើ |

UI និង UX ត្រូវធ្វើការជាមួយគ្នា។ Website អាចស្អាត ប៉ុន្តែបើប្រើពិបាក នោះ UX មិនល្អទេ។

## 5. Typical Design Workflow
1. **Understand the problem** — ស្វែងយល់ថា Website ត្រូវដោះស្រាយបញ្ហាអ្វី។
2. **Research users** — ស្វែងយល់ពីអ្នកប្រើប្រាស់។
3. **Create wireframes** — គូររចនាសម្ព័ន្ធទំព័រដំបូង។
4. **Create UI design** — ជ្រើសរើសពណ៌ អក្សរ រូបភាព និង Components។
5. **Build prototype** — ភ្ជាប់ Screens ឱ្យអាចសាកល្បងចុចបាន។
6. **Test and improve** — សាកល្បង និងកែលម្អ។

## 6. First Practice
គិតពី Online Shop មួយដែលអ្នកចង់បង្កើត ហើយសរសេរ៖
- តើអ្នកប្រើប្រាស់គោលដៅជានរណា?
- តើពួកគេចង់ធ្វើអ្វីនៅលើ Website?
- តើ Website ត្រូវមានទំព័រអ្វីខ្លះ?
- តើអ្វីខ្លះធ្វើឱ្យការប្រើប្រាស់ងាយស្រួល?

## Quick Check
1. UI មានន័យដូចម្តេច?
2. UX ផ្តោតលើអ្វី?
3. តើ Website ស្អាត ប៉ុន្តែប្រើពិបាក អាចចាត់ទុកថា UX ល្អទេ?
4. ហេតុអ្វីយើងគួរបង្កើត Wireframe មុន UI Design?
