# Module 05: Prototyping and Interaction

## គោលបំណង

នៅចុងបញ្ចប់ Module នេះ អ្នកអាច៖

- បង្កើត prototype flows និង interactions។
- ប្រើ overlays, navigation និង scroll behavior។
- ជ្រើស transitions/animations ដែលសមនឹង user journey។
- ប្រើ variables និង conditional actions សម្រាប់ prototype state ប្រសិនបើ account គាំទ្រ។
- សាកល្បង prototype និងសរសេរកំណត់ចំណាំអំពី behavior/limitations។
