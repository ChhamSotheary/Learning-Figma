# Exercise 01: Interactive Checkout Prototype

## គោលដៅ

បង្កើត clickable prototype សម្រាប់ shopping checkout flow ដោយមាន navigation, overlays, scrolling, animation និង state handling។

## តម្រូវការអប្បបរមា

បង្កើត screens៖

- Product detail។
- Cart ដែលមាន items។
- Empty cart state។
- Checkout form។
- Order confirmation។

បន្ថែម interactions៖

- Add to cart និង cart state/counter។
- Open/close cart overlay ឬ navigate ទៅ Cart screen។
- Remove item និងបង្ហាញ empty state។
- Continue ទៅ checkout និង confirmation។
- Back navigation និង error/validation state មួយ។
- Scroll behavior សម្រាប់ page ដែលមាន content លើស frame។

## ដំណើរការ

1. គូស user flow មុនភ្ជាប់ frames។
2. កំណត់ flow starting point។
3. បង្កើត interactions ពី trigger, action និង destination។
4. បន្ថែម overlay និង scroll behavior តាមតម្រូវការ។
5. ប្រើ animation តែពេលជួយឱ្យ flow យល់ច្បាស់។
6. ប្រើ variables/conditionals ប្រសិនបើ feature អាចប្រើបានក្នុង account របស់អ្នក។
7. Preview branch ទាំងអស់ និងកត់ត្រា interaction ដែលមិនទាន់អាច simulate បាន។

## Rubric

- User flow និង navigation: 25%
- Interaction coverage និង states: 25%
- Overlays/scroll behavior: 15%
- Animation មានគោលបំណង: 15%
- Naming, starting points និងការសាកល្បង: 20%

## Self-review

- តើអ្នកប្រើអាចត្រឡប់ពី checkout ទៅ cart បានទេ?
- តើ empty cart, success និង error states មាន?
- តើ overlay អាចបិទបាន?
- តើ scrolling និង fixed elements ដំណើរការត្រឹមត្រូវ?
- តើ animation ធ្វើឱ្យ flow ងាយយល់ ឬរំខាន?

## Deliverables

- Figma file មាន screens និង prototype flow។
- Link សម្រាប់ preview/review។
- Flow diagram ឬកំណត់ចំណាំអំពី variables/conditions និង limitations។
