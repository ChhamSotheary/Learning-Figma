# Lesson 01: Prototype Flows and Interactions

## គោលបំណង

រៀនភ្ជាប់ frames និង elements ដើម្បីបង្ហាញ user journey មួយក្នុង prototype។ យល់ពី flow starting point, trigger, action, destination និង animation។

## 1. Prototype ជាអ្វី?

Prototype ជាការក្លែងធ្វើ interaction រវាង screens ដោយមិនចាំបាច់សរសេរកូដ។ វាអាចជួយពិនិត្យ navigation, labels, screen order និង interaction assumptions ជាមួយក្រុម ឬអ្នកប្រើ។

Prototype មិនមែនជាផលិតផលដំណើរការពិតទេ។ កុំសន្មតថា prototype បញ្ជាក់ performance, data behavior ឬ accessibility ទាំងអស់បាន។

## 2. Flow Starting Point

Flow គឺជាផ្លូវដែលអ្នកប្រើធ្វើដំណើរឆ្លង frames។ ជ្រើស frame ដំបូងរបស់ journey ហើយកំណត់ flow starting point ក្នុង Prototype tab។ អាចមានច្រើន flows ដើម្បីសាកល្បង journeys ផ្សេងៗ ដូចជា customer sign-up និង checkout។

ដាក់ឈ្មោះ flow តាមគោលបំណង ដើម្បីឱ្យអ្នកសាកល្បងដឹងថាត្រូវចាប់ផ្តើមពីណា។

## 3. Trigger, Action និង Destination

- Trigger: ព្រឹត្តិការណ៍ដែលចាប់ផ្តើម interaction ដូចជា On click, On tap ឬ drag gesture។
- Action: អ្វីដែល prototype ធ្វើ ដូចជា Navigate to, Open overlay, Back ឬ Scroll to។
- Destination: frame ឬ overlay ដែល interaction ទៅដល់។
- Animation: របៀបប្ដូរពី state មួយទៅមួយ។

ជ្រើស hotspot ដែលសមហេតុផល ហើយកំណត់ trigger/action ក្នុង Prototype tab។ អ្នកក៏អាចអូស connection ពី object ទៅ destination frame តាម canvas បាន។

## 4. បង្កើត Sign-up Flow

បង្កើត frames៖ Welcome, Create account, Success។ ភ្ជាប់ CTA នៅ Welcome ទៅ Create account; ភ្ជាប់ Create account ទៅ Success។ បន្ថែម Back navigation ប្រសិនបើ flow ត្រូវការវា។

Preview prototype ហើយចុច controls ដូចអ្នកប្រើពិត។ ពិនិត្យថា button label ស្របនឹងលទ្ធផល និងគ្មាន dead-end ដោយគ្មានផ្លូវត្រឡប់។

## កំហុសទូទៅ

- ភ្ជាប់ hotspot ពី element ខុស។
- មិនកំណត់ flow starting point។
- បង្កើត button ដែលមើលទៅអាចចុចបាន ប៉ុន្តែមិនមាន interaction។
- ច្រឡំ action destination ជាមួយ trigger។
- ប្រើ animation យូរពេក ឬមិនស្របនឹង purpose។

## Quick Check

1. Flow starting point មានតួនាទីអ្វី?
2. Trigger ខុសពី action ដូចម្តេច?
3. តើ hotspot អាចជាអ្វីខ្លះ?
4. ហេតុអ្វី prototype មិនអាចជំនួស usability testing ទាំងស្រុង?
