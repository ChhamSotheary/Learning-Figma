# Lesson 01: Discovering and Using Figma Plugins

## គោលបំណង

ស្វែងរក និងប្រើ Plugins ដើម្បីជួយការងារជាក់លាក់ក្នុង Figma ដោយពិនិត្យប្រភព, permissions និងលទ្ធផល មុនដាក់បញ្ចូលក្នុង project។

## 1. Plugin ជាអ្វី?

Plugin ជាឧបករណ៍បន្ថែមដែលអាចជួយបង្កើត content, icons, charts, diagrams, accessibility checks ឬការងារដដែលៗ។ Plugins ខុសពី built-in tools ហើយមុខងារ/permissions អាស្រ័យលើ plugin នីមួយៗ។

ស្វែងរកក្នុង Figma Tools/Plugins ឬ Resources menu តាម UI ដែលអ្នកកំពុងប្រើ។ ពិនិត្យ publisher, description, reviews/usage information, last update និង permission prompt មុនប្រើ។

## 2. ជ្រើស Plugin តាម Task

មុនស្វែងរក សរសេរ task ច្បាស់៖ “បង្កើត placeholder avatars សម្រាប់ prototype” ល្អជាង “ត្រូវការ plugin រចនា”។ បន្ទាប់មកវាយតម្លៃ៖

- តើ plugin ដោះស្រាយបញ្ហាដែលអ្នកមានមែនទេ?
- តើវាត្រូវការ access ទៅអ្វីខ្លះ?
- តើ content ដែលបង្កើតបានប្រើបានក្នុង license/project របស់អ្នកទេ?
- តើអាចធ្វើដូចគ្នាដោយ built-in Figma tools ឬទេ?
- តើអ្នកអាច undo ឬលុប generated content បានទេ?

កុំផ្តល់ permission លើសពីអ្វីដែល task ត្រូវការ ហើយកុំផ្ញើ customer/private data ទៅ plugin ដោយគ្មានការអនុញ្ញាត។

## 3. របៀបប្រើ និង Review

1. បើក file ឬ selection ដែលត្រូវការធ្វើការ។
2. បើក plugin ពី Tools/Plugins។
3. អាន permission prompt និងបញ្ជាក់ថាសមនឹងគោលបំណង។
4. សាកល្បងលើ duplicate page ឬ test frame ប្រសិនបើ plugin នឹងបន្ថែម/កែ layers ច្រើន។
5. Review generated output, naming, alignment និង assets។
6. Undo ឬលុប output ដែលមិនត្រឹមត្រូវ។
7. កត់ឈ្មោះ plugin និងលទ្ធផលក្នុង project notes ប្រសិនបើ team ត្រូវដឹង។

## 4. Plugin និង Accessibility/Quality

Plugin អាចផ្តល់ជំនួយពិនិត្យ contrast, content ឬ generated assets ប៉ុន្តែមិនអាចជំនួសការពិនិត្យដោយមនុស្សបានទាំងស្រុង។ ពិនិត្យ result ដោយភ្នែក និងតាម design requirements។ សម្រាប់ generated images/icons សូមផ្ទៀងផ្ទាត់ licensing និងភាពសមស្របនឹង brand។

## កំហុសទូទៅ

- ដំឡើង/ប្រើ plugin ដោយមិនអាន permission prompt។
- ជឿ generated output ដោយមិនពិនិត្យ។
- ប្រើ plugin លើ original file ដោយគ្មាន duplicate/undo plan។
- ចែករំលែក sensitive content ទៅ plugin មិនចាំបាច់។
- បន្ថែម plugin ដើម្បីបន្ថែម features ដោយមិនដោះស្រាយ task ជាក់ស្តែង។

## Quick Check

1. តើអ្នកពិនិត្យអ្វីខ្លះមុនប្រើ plugin?
2. ហេតុអ្វីត្រូវសាកល្បងលើ duplicate page សម្រាប់ bulk changes?
3. តើ plugin-generated output ត្រូវ review ផ្នែកណាខ្លះ?
4. តើពេលណាមិនគួរផ្ញើ data ទៅ plugin?
