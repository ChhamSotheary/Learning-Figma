# Module 07: Plugins and Final Project

## គោលបំណង

នៅចុងបញ្ចប់ Module នេះ អ្នកអាច៖

- ស្វែងរក និងប្រើ Figma plugins ដោយពិនិត្យ permission និង output។
- ដាក់ plugin ក្នុង workflow ដោយមាន review checkpoints។
- រៀបចំ capstone ពី brief ទៅ prototype និង handoff។
- បង្ហាញ design decisions, evidence, limitations និង final deliverables។

## ចំណាំ

Plugin គឺជាឧបករណ៍បន្ថែម។ សូមពិនិត្យ publisher, permissions, data handling និង licensing មុនប្រើ។ Final project អាចប្ដូរទៅប្រភេទ product ផ្សេង ប្រសិនបើរក្សា user flow, responsive design, components, prototype និង handoff requirements បាន។
