# Final Project 01: Mobile Commerce App

## Brief

រចនា mobile commerce app មួយដែលជួយអ្នកប្រើស្វែងរក និងទិញផលិតផលក្នុងប្រភេទមួយដែលអ្នកជ្រើសរើស។ ផ្តោតលើ user journey ចាប់ពីការរកផលិតផល ដល់ការមើល order confirmation។

## User Flow

បង្កើត flow យ៉ាងហោចណាស់មួយ៖

Home → Category/Search → Product detail → Cart → Checkout → Confirmation

បន្ថែម empty cart និង form error state យ៉ាងហោចណាស់មួយ។ កុំបង្ហាញ ឬប្រមូលព័ត៌មានកាតពិតក្នុង prototype។

## Screens និង Design Requirements

- Onboarding ឬ Home screen។
- Search/category results។
- Product detail។
- Cart និង empty state។
- Checkout form និង validation error។
- Order confirmation។
- Responsive adaptation សម្រាប់ mobile និង tablet ឬ desktop view មួយ។
- Design system តូចមាន colors, typography, spacing, buttons, fields និង product cards។
- Prototype links សម្រាប់សកម្មភាពសំខាន់ៗ។
- Handoff notes និង export settings សម្រាប់ assets។

## ដំណាក់កាលអនុវត្ត

1. សរសេរ brief summary, audience និង assumptions។
2. គូស user flow និង content list។
3. បង្កើត low-fidelity wireframes។
4. កំណត់ design tokens និង components។
5. បង្កើត high-fidelity screens និង responsive versions។
6. ភ្ជាប់ interactions និង prototype states។
7. សាក usability ជាមួយអ្នកពិនិត្យម្នាក់ ឬច្រើន។
8. កែ design ហើយរៀបចំ Dev Mode/handoff notes។
9. Export assets និងបង្កើត project presentation page។

## Rubric

- User flow និង task completion: 20%
- Visual hierarchy និង accessibility: 20%
- Components/design system consistency: 20%
- Responsive behavior: 15%
- Prototype interactions/states: 15%
- Handoff, assets និង file organization: 10%

## Deliverables

- Figma file ដែលមាន pages សម្រាប់ Research/Flow, Wireframes, UI, Components និង Handoff។
- Prototype preview link។
- Mobile screens និង responsive counterpart។
- Design tokens/components។
- Handoff notes, open questions និង exported assets។
- Short case study៖ problem, process, decisions, feedback និង changes។

## Self-review

- តើអ្នកប្រើអាចបញ្ចប់ purchase journey ដោយមិនជាប់ dead-end?
- តើ price, availability និង primary CTA ងាយរកឃើញ?
- តើ empty/error/loading states មាន?
- តើ design ប្រើបាននៅ viewport ផ្សេង?
- តើ developer អាចយល់ behavior និង assets ដោយមិនទាយ?
- តើ case study បែងចែកបានរវាង evidence និង assumptions?
